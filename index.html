Set as Homepage / 设为主页

Copy this address into your browser's homepage settings.
将此地址复制到浏览器的主页设置中。

  • Chrome (desktop / 电脑): Settings → Appearance → Show home button → enter this address. To open it at launch, use Settings → On startup.
  • Edge (desktop / 电脑): Settings → Start, home, and new tab page → Show home button → enter this address.
  • Firefox (desktop / 电脑): Settings → Home → Homepage and new windows → Custom URLs.
  • Safari (Mac): Safari → Settings → General → Homepage. Choose Homepage for new windows or tabs.

On a phone, save this page as a bookmark or use your browser's Add to Home Screen option when available.
手机上可收藏此页面，或使用浏览器提供的“添加到主屏幕”功能。
